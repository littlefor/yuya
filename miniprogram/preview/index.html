WeChat Mini Program

语芽小程序已打包

微信小程序不能像网页那样跑在浏览器里，需要用微信开发者工具导入源码。Docker 负责注入接口地址并生成可下载的代码包。

当前接口地址：__API_BASE__

下载小程序代码包 打开 PC 网页版

导入步骤（官方开发者工具）

  1. 安装并打开 微信开发者工具。
  2. 选择「小程序」，导入项目目录 miniprogram/（或解压上面的 zip）。
  3. AppID 可先用测试号 / touristappid；正式上线再换成你的 AppID。
  4. 详情 → 本地设置：勾选「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」。
  5. 确保 Docker 栈已启动，PC 端 http://localhost:8080 能打开，小程序才会请求到同一套 API。
  6. 体验账号：demo@linguaseed.app / demo123

正式发布

  1. 在微信公众平台注册小程序，拿到 AppID，写入 project.config.json。
  2. 把后端放到 HTTPS 域名，并在公众平台配置 request 合法域名。
  3. 发音走有道词典音频，正式环境还需配置 downloadFile / 音频合法域名 dict.youdao.com。
  4. 开发者工具上传代码 → 提交审核。
